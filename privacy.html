はじめに

Duebell Fleet（以下「本アプリ」）は、社用車・営業車・トラックの車検・保険・点検・整備の期限と記録を管理する Windows 向けデスクトップアプリです。本ポリシーは、本アプリが利用者の情報をどのように取り扱うかを説明します。

本アプリは個人情報を一切収集・送信・共有しません。入力したデータはすべて利用者のデバイス（または利用者が指定したフォルダ）内にのみ保存されます。

1. 収集する情報

  • 本アプリは利用者の個人情報を収集しません。
  • 利用者が入力した次のデータは、利用者のデバイス内のデータベースファイル（既定は「ドキュメント」フォルダの DuebellFleet\duebellfleet.db。利用者が社内の共有フォルダなど別の場所を指定した場合はその場所）に保存されます。
    • 車両の情報（車両名、ナンバー、車台番号、担当者、部署など）
    • 期限と更新の履歴、整備記録、走行距離、費用
    • 添付した書類（データベースと同じ場所の attachments フォルダにコピーされます）
    • 自動・手動のバックアップ（同じ場所の backup フォルダ）
  • 次回起動時に同じ状態で開く目的で、次の設定が本アプリの設定ファイル（duebellfleet.ini。Microsoft Store 版ではアプリ専用の領域）に保存されます：表示言語、同意した免責事項の版、データベースの場所、一覧の列幅、ウィンドウの位置と大きさ。
  • 共有フォルダで使う場合、同時編集を防ぐためのロックファイルに、編集中の PC 名・Windows のユーザー名・時刻が書かれます。これは同じフォルダを使う利用者の画面に「編集中の人」として表示するためだけに使われます。
  • これらのファイルが外部へ送信されることはなく、開発者がアクセスすることもできません。

2. 利用目的

上記のデータは、本アプリの機能（期限の管理、表示・設定の復元、共有フォルダでの排他制御）を提供する目的にのみ使用します。それ以外の目的では使用しません。

3. ネットワーク・オンラインサービス

本アプリはインターネットに接続せずに動作します。テレメトリ・利用解析（アナリティクス）・広告・トラッキング・ユーザーアカウントの仕組みを一切含みません。

Microsoft Store 版では、試用期間とライセンスの確認、および購入を Windows と Microsoft Store の仕組みを通じて行います。これに伴う情報の取り扱いは Microsoft のプライバシーに関する声明に従います。本アプリが開発者に情報を送ることはありません。

4. 第三者への提供

本アプリはデータを収集しないため、いかなるデータも第三者へ販売・提供・開示しません。

5. 書き出し機能について

CSV・印刷用 HTML・カレンダー（.ics）への書き出しは、利用者が明示的に操作したときにのみ実行され、書き出し先は利用者が指定した場所（印刷用 HTML は一時フォルダ）です。本アプリが外部へ送信することはありません。

6. データの保存期間と削除

データは、利用者が削除するまで保存されます。本アプリをアンインストールしても、業務データを失わないようデータベース・バックアップ・添付書類（「ドキュメント」の DuebellFleet フォルダ）は残ります。設定ファイルはアンインストール時に削除されます。完全に消去するには、「ドキュメント」の DuebellFleet フォルダ（および利用者が指定した保存場所）を削除してください。

7. セキュリティ

データは利用者のデバイスまたは利用者が指定したフォルダにのみ保存されるため、その安全性は利用者のデバイス・ネットワークのセキュリティ対策に依存します。

8. 子どものプライバシー

本アプリは、子どもを含むいかなる利用者からも情報を収集しません。

9. 本ポリシーの変更

本ポリシーは必要に応じて改定することがあります。最新版はこのページに掲載します。

10. お問い合わせ

本ポリシーや本アプリに関するお問い合わせ先：G.Works.902@gmail.com

English

Introduction

Duebell Fleet ("the App") is a Windows desktop application that keeps the deadlines and records of company vehicles — inspections, insurance, periodic checks and maintenance. This policy explains how the App handles your information.

The App does not collect, transmit, or share any personal data. Everything you enter is stored only on your device (or in a folder you choose).

1. Information we collect

  • The App does not collect any personal information.
  • The data you enter is stored in a database file on your device (by default DuebellFleet\duebellfleet.db in your Documents folder, or another location you choose, such as a shared folder on your company network):
    • Vehicle information (name, plate, VIN, assignee, department and so on)
    • Due dates and renewal history, maintenance records, odometer readings, costs
    • Attached documents (copied to an attachments folder next to the database)
    • Automatic and manual backups (a backup folder next to the database)
  • To open the App the way you left it, the following settings are stored in the App's settings file (duebellfleet.ini; in the Microsoft Store version, in the App's own storage): display language, the version of the disclaimer you agreed to, the database location, column widths and the window position and size.
  • When the database is in a shared folder, a lock file records the editing PC's name, the Windows user name and the time, to prevent simultaneous editing. It is used only to show other users of the same folder who is editing.
  • These files never leave your device, and the developer cannot access them.

2. How we use information

The data is used only to provide the App's functionality (managing deadlines, restoring the display and settings, and locking a shared database). It is not used for any other purpose.

3. Network and online services

The App works without an internet connection. It contains no telemetry, analytics, advertising, tracking or user accounts.

In the Microsoft Store version, the trial period, the licence check and purchases are handled by Windows and the Microsoft Store; the Microsoft Privacy Statement applies to that. The App itself never sends information to the developer.

4. Sharing with third parties

Because the App does not collect data, it does not sell, share or disclose any data to third parties.

5. Export features

Export to CSV, printable HTML and calendar files (.ics) runs only when you ask for it, and writes to the location you choose (printable HTML goes to the temporary folder). The App never transmits anything.

6. Retention and deletion

Data is kept until you delete it. Uninstalling the App leaves the database, backups and attached documents (the DuebellFleet folder in Documents) in place so that business data is not lost; the settings file is removed with the App. To remove everything, delete the DuebellFleet folder in Documents (and any other location you chose for the database).

7. Security

Data is stored only on your device or in a folder you choose, so its security depends on the security measures of your device and network.

8. Children's privacy

The App does not collect information from anyone, including children.

9. Changes to this policy

This policy may be updated as needed. The latest version is always published on this page.

10. Contact

Questions about this policy or the App: G.Works.902@gmail.com
